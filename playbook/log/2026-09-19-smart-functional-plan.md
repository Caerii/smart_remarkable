## Controller and main functions

- `ops/smart-functional-peers.sha256` is the immutable eleven-peer manifest.
- `ops/deploy-smart-functional.sh` runs local tests, matches the exact Ferrari
  SSH host key, stages a hash-receipted eight-file bundle, obtains the device
  backup, verifies its Mac copy, and requests guarded functional activation.
- `ops/device-install-smart-functional.sh` accepts only `functional` mode.
  `verify_stage` checks the complete stage set and reviewed receipt;
  `verify_qmd_set` checks every peer hash, ownership and mode;
  `verify_smart` checks the complete installed app contract and requires idle
  assistants; `verify_live` checks exact model/build/libraries/service inputs,
  including the live-proven root ownership and modes of the executed ReMagic
  helper (0700), start helper (0755) and stock helper (0755);
  `snapshot` and `preserved_snapshot` detect races and settings changes.
- The device `prepare` phase only creates root-private recovery data. It verifies
  the original inert receipt `20260814T232837Z-37203`, archives the QMD directory,
  unchanged Dispatch launcher, Smart app and Smart/Gestik settings. The copied
  archive contains private configuration, so its Mac directory remains 0700.
- `activate` requires the exact before-snapshot and independently verified backup,
  runs only in its named transient unit, proves hybrid-cgroup support, and arms
  an independent 180-second rollback before replacing the QMD. The pinned ReMagic
  wrapper supplies a second UI watchdog. Commit requires all twelve load markers
  exactly once, expected changed-resource markers, no relevant QML failure,
  stable stock executable/mappings, zero restarts and a read-only root.
- `ops/rollback-smart-functional.sh` first kills and proves the entire installer
  cgroup empty at `/sys/fs/cgroup/unified`, including descendants, then rechecks
  commit. It restores only the exact saved inert QMD and requests pinned stock
  xochitl. Before claiming rollback or releasing its lock, it proves the same
  PID and `/proc` start time across five one-second samples, zero automatic
  restarts, no `LD_PRELOAD`, no mappings under `/home/root/xovi/`, and a read-only
  root. Unreadable/empty maps, missing process data or drift fail closed.
  Unknown bytes are preserved and marked for manual inspection. It
  never restores notebooks, date history, settings or the unrelated app panel.

The shared Smart deployment lock prevents an old app installer or canary from
racing the swap. Known independent package/Dates/Dispatch mutation units are
also rejected. No new persistent service is installed.
